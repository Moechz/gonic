# Changelog

All notable user-visible changes to the Gonic TOS application package.

## 0.23.0-1 — 2026-11-15

### Added
- First release. Gonic (`sentriz/gonic:v0.23.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8154 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/gonicdocker/`.
